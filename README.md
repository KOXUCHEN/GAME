# Gem Lab

A 3D gemstone identification simulator built with Godot.

Gem Lab is an independent software project that explores how gemstone examination and identification can be represented in an interactive 3D environment. The project combines game development, interactive systems, 3D assets, and an AI-assisted development workflow.

## Project Goal

The goal of Gem Lab is to turn the gemstone identification process into an interactive experience. Instead of presenting gemstone information only as static text, the project is designed around examining specimens and interacting with virtual gemological tools.

## What I Built

- A 3D environment for gemstone examination
- Interactive workflows for inspecting and identifying gemstones
- Godot scenes and GDScript-based gameplay logic
- Integration of gemstone, laboratory, and instrument assets
- Iterative UI and interaction experiments
- A working project that I continue to develop and refine

## Tech Stack

## Development Approach

I use Codex extensively as an AI development tool for this project.

My role is to define the product behavior and requirements, break problems into smaller tasks, test the implementation, identify failures, and iterate on the result. I use the coding agent to accelerate implementation and debugging rather than treating generated code as automatically correct.

A typical development loop is:

```text
Problem definition
        ↓
Break down the system
        ↓
Implementation with Codex
        ↓
Test in Godot
        ↓
Identify bugs / incorrect behavior
        ↓
Iterate and validate
```

This project has been one of the ways I have learned software development: by starting with a product I wanted to build and learning the engineering concepts required to make it work.
